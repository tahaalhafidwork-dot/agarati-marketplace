# Sahibinden mobile UI — visual brief (public Play Store)

Captured from Google Play screenshots for `com.sahibinden` (2026-09-26).
**Inspiration only** — do not copy yellow brand, logos, or proprietary assets.
AGARATİ adaptations: Arabic RTL, primary `#0F2744` + gold `#B8956C`, real-estate focus only.

## Screens observed

1. **Home / categories**
   - Blue top bar: menu · brand · profile · “post ad” (camera+)
   - Full-width search: keyword / listing No · voice · scan
   - Vertical category rows: colored circular icon · title · subtitle · chevron
   - Categories: Emlak, Vasıta, Parts, Shopping, Yepy, Machinery, Services, Tutors, Jobs

2. **Listing detail**
   - Top photo carousel
   - Tabs: İlan Bilgileri · Açıklama · Konum
   - Loud price · listing date · listing No
   - Sticky bottom **Call** CTA

3. **Results grid** (shopping-style)
   - 2-column cards: image · short title · bold price

4. **Map search**
   - Price pins on map · filter chips (e.g. Fiyat) · bottom results sheet

5. **Create listing**
   - Add photo · title · description · price · category fields

## Design thesis for AGARATİ Replit prototype

| Keep (structure) | Change (brand) |
| --- | --- |
| Dense classifieds IA | Ink navy `#0F2744` + gold instead of blue/yellow |
| Search-first home | Arabic RTL chrome |
| Category drill-down | Real-estate only (no cars/shopping) |
| Price-forward cards | 4/3 listing images |
| Sticky contact CTA | No exact street address public |
| Facets + list/map entry | Map as placeholder later |
